# حِلْقَتي — قرارات MVP المحسومة

> **المرجع الإنجليزي:** [MVP_DECISION_REGISTER.md](../product/MVP_DECISION_REGISTER.md)
> **آخر تحديث:** 2026-08-28
> **النطاق:** خلاصة قرارات المنتج والأعمال؛ لا تعيد هذه الوثيقة تفاصيل التنفيذ.

## الحسابات والأدوار

| الموضوع | القرار |
|---|---|
| التسجيل | لا توجد حسابات تعتمد على الهاتف وحده؛ البريد أو حساب اجتماعي مطلوب، والهاتف وسيلة مساندة فقط. |
| التحقق من هوية المعلم | اختياري في MVP. |
| الأدوار | داخل كل حلقة على حدة، ويمكن للشخص الجمع بين أدوار مختلفة في حلقات مختلفة. |
| نموذج المعلم المشارك | مؤجل لما بعد التجربة؛ MVP يتضمن معلماً ومشرفاً. |
| حذف حساب المعلم | تُؤرشف الحلقة ويُخطر الأعضاء؛ يلزم تعيين مشرف قبل الحذف. |

## طابور التسميع

| الموضوع | القرار |
|---|---|
| الاعتذار من جولة | مسموح. الأصل أن يراجعه المعلم أو المشرف، ويمكن للحلقة اختيار الموافقة التلقائية. لا يترتب عليه عقاب. |
| مؤقت الطالب | غير موجود في MVP؛ المعلم يدير وقت التسميع بأسلوب الحلقة. |
| الترتيب المسبق | مسموح قبل الجلسة. |
| الطالب المتأخر | يوضع افتراضياً بعد الحاضرين، ويمكن ضبط السياسة للجلسة. |
| تكرار الطالب في الجولة | لا؛ موضع واحد في الجولة، وجولات متتابعة عند الحاجة إلى تسميع آخر. |
| مرونة الجلسة | يضبط المعلمون سياسة تكوين الطابور والاعتذار ورؤية التقييمات وتصحيحها للمستقبل. |
| المشاركة الصوتية | الطابور طوعي لتنظيم الترتيب وحالة الدور المعروضة فقط؛ لا يتحكم في حق الطالب في المشاركة الصوتية داخل جلسة مصرّح بها. |

## التواصل والجلسات

| الموضوع | القرار |
|---|---|
| الإعلانات | لا قناة إعلانات مستقلة في MVP؛ الرسائل المثبتة تكفي. |
| الملاحظات الصوتية | حتى 5 دقائق و20 ميغابايت. |
| التفاعلات | مؤجلة إلى P2. |
| شكل الجلسة | صوت فقط في MVP؛ الفيديو مؤجل. |
| مدة الجلسة | حتى 4 ساعات، مع إنهاء الجلسة الخاملة بعد 30 دقيقة من مغادرة آخر مشارك. |
| التسجيل | غير متاح في MVP. أي طرح لاحق يتطلب موافقة واضحة من الجميع وسياسة احتفاظ معلنة. |
| الإشراف | للمعلم والمشرف أدوات متساوية لإدارة الجلسة، مثل الكتم والإزالة والقفل والإنهاء. |
| رفع اليد | متاح لكل مشارك نشط لتنظيم الحوار، ولا يغير ترتيب الطابور تلقائياً. |

## الجدولة والتقدم والمحتوى

| الموضوع | القرار |
|---|---|
| الجلسات المفردة | مسموحة، بما فيها جلسات التعويض والمكثفات. |
| متابعة التقدم | تنشأ من التسميع في الجلسات؛ لا توجد متابعة ذاتية يضيفها الطالب في MVP. |
| التكرار | يمكن تسميع القسم نفسه مرات متعددة؛ يحتفظ المنتج بالتاريخ الكامل. |
| نص المصحف | يعتمد نص Tanzil.net المرخص للاستخدام. |
| تشغيل تلاوة المصحف | ليس ضمن MVP. |
| التقارير الشهرية عبر البريد | ليست ضمن MVP؛ تصدير PDF اليدوي خيار مستقبلي. |
| الذكاء الاصطناعي للتجويد أو التخطيط | مؤجلان إلى ما بعد MVP. |

## نموذج الأعمال

- لا إعلانات في أي فئة.
- الفئة المجانية هي نقطة البداية للتجربة؛ حدها 3 حلقات و30 طالباً لكل حلقة.
- الفئة المميزة تزيل الحدود وتضيف قيمة معتمدة بعد MVP.
- المؤسسات تبدأ ذاتية الخدمة في MVP، ثم تتوسع بناءً على نجاح التجارب.
- لا يُفعّل التسجيل أو الفيديو لمجرد توفرهما؛ يجب أن يسبقهما قرار تجاري وخصوصي واضح.
