# حِلْقَتي — منصة حلقات تحفيظ القرآن الكريم

> **منصة واحدة لكل حلقة تحفيظ.**

---

## 📖 الرؤية

حِلْقَتي هو تطبيق مصمم حصرياً لخدمة **حلقات تحفيظ القرآن الكريم**. اليوم، يضطر المعلمون والطلاب إلى التنقل بين تطبيقات متعددة: واتساب أو تيليغرام للمحادثات، وزووم أو جوجل ميت لجلسات الفيديو مع قيود مزعجة على الوقت، وجداول بيانات أو دفاتر ورقية لمتابعة التقدم.

**حِلْقَتي** يستبدل كل ذلك بتطبيق واحد مصمم خصيصاً لاحتياجات حلقات التحفيظ الروحية والتعليمية.

---

## 🌟 المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🕌 **إدارة الحلقات** | إنشاء حلقات، دعوة الطلاب بأكواد/روابط، تعيين المشرفين |
| 🎙️ **نظام طابور التسميع** | الميزة الفريدة — طابور منظم للجلسات المباشرة مع تتبع كل جولة |
| 💬 **المحادثات الفورية** | رسائل جماعية وخاصة مع رسائل صوتية وملفات وتثبيت الرسائل |
| 📹 **الجلسات المباشرة** | صوت/فيديو بلا حد زمني عبر LiveKit، محسَّن لجودة التلاوة |
| 📅 **الجدول والمواعيد** | جداول أسبوعية متكررة، تذكيرات، تتبع الحضور والغياب |
| 📊 **متابعة التقدم** | سجلات تحفيظ مفصلة لكل طالب مع درجات وخرائط القرآن |
| 🔔 **الإشعارات الذكية** | إشعارات فورية (FCM) وداخل التطبيق |
| 👨‍👩‍👧 **لوحة ولي الأمر** | يتابع الوالدان تقدم أبنائهم وحضورهم |
| 🏢 **منصة المؤسسات** *(مستقبلاً)* | إدارة المدارس ومراكز تحفيظ القرآن بالكامل |

## 🔥 نظام طابور التسميع

الميزة الأكثر تميزاً في حِلْقَتي. خلال الجلسة المباشرة، يدير المعلم **طابوراً منظماً** من الطلاب يُسمِّعون واحداً تلو الآخر. حالة كل طالب ظاهرة للجميع:

- ⏳ **في الانتظار** — لم يُسمِّع بعد
- 🎙️ **يُسمِّع الآن** — مُبرَز لجميع المشاركين في الجلسة
- ✅ **انتهى** — أكمل التسميع وسُجِّلت درجته
- ⏭️ **تم التخطي** — غائب أو تخطّاه المعلم

يمكن **إعادة ضبط الطابور واستخدامه عدة مرات** في الجلسة الواحدة — مثلاً: الجولة الأولى للحفظ الجديد من سورة البقرة، ثم إعادة الضبط للجولة الثانية للمراجعة من سورة الفاتحة. كل جولة تتتبع السورة والآية البداية والآية النهاية.

## 🛠️ التقنيات المستخدمة

| الطبقة | التقنية | السبب |
|--------|---------|-------|
| **التطبيق** | Flutter (Dart) | كود واحد → iOS وAndroid والويب |
| **الخادم** | Go (Golang) | أداء عالٍ، تزامن ممتاز للمحادثات الفورية |
| **قاعدة البيانات** | PostgreSQL | بيانات علائقية قوية |
| **المحادثات الفورية** | WebSocket (Go) | تأخير منخفض، تحكم كامل |
| **الصوت/الفيديو** | LiveKit (WebRTC، مستضاف ذاتياً) | مفتوح المصدر، بلا حدود زمنية، مُحسَّن للتلاوة |
| **تخزين الملفات** | MinIO (متوافق مع S3، مستضاف ذاتياً) | فعّال من حيث التكلفة، بلا قيود خارجية |
| **الإشعارات** | Firebase Cloud Messaging (FCM) | معيار الصناعة، متعدد المنصات |
| **المصادقة** | Firebase Auth | تسجيل دخول اجتماعي (Google, Apple)، OTP هاتفي |
| **النشر** | Docker Compose → Kubernetes | بدء رخيص (~8$/شهر)، قابل للتوسع للعالمية |
