## Implementation Strategy

Build the durable recipient history/token/dispatcher foundation first, then add source handoffs and Flutter consumption, preferences/read state, lifecycle notices, and finally manager-deletion enablement. Do not enable manager deletion on an unverified dispatcher. No task authorizes generic event infrastructure, speculative event types, or source data duplication.
